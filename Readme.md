# Portfolio Tracker

This repo creates a simple web app to tracking the performance of my stocks.

## Problem Statement

Currently, I have to navigate to Robinhood or Schwab to track how my stocks are performing. 
The main issue I have with this is the performance of these apps, especially on my phone.
These apps provide a lot of functionality that results in slowing down the performance.

## Main Use Case

My main use case is to get a quick glance of how my stocks are performing on a daily level.
Since I open these apps multiple times a day, I want a lightweight UI for this use case.

## Stack

1. Using DuckDB as my main database
2. Using Python and Pandas for data manipulation
3. Using Streamlit for the UI and webapp
4. Using Docker to deploy
5. Using tailscale to be able to access my webapp from outside my local network
